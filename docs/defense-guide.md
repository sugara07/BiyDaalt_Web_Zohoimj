# Гишүүн бүрийн хоёр минутын хамгаалалт

Хуудсаа Live Server эсвэл локал HTTP серверээр нээнэ. Танилцуулгадаа хариуцсан таван хуудсынхаа зориулалт, холбогдох код, нэг ажилладаг үйлдэл, өөрийн хийсэн өөрчлөлтийн нотолгоог үзүүлнэ. Доорх хугацаа нь бэлтгэлийн жишиг.

`fetch()` дуусах хүртэл төлөв `loading` байна. Өгөгдөлтэй бол `success`, хүссэн жагсаалт хоосон бол `empty`, HTTP 404 болон формат буруу үед `error` гарна. `fetch()` HTTP 404 хариуг өөрөө алдаа болгон зогсоодоггүй тул `response.ok`-г шалгана. Демо захиалга, дуртай хоолны сонголт браузерт хадгалагдана.
