# F.ITM202 бие даалтын шалгуурын тулгалт

Бие даалт бүр багийн 4, хувь хүний 12 онооны шалгууртай. Доорх төлөв нь код ба туршилтын нотолгоог заана. Оноог оюутан тус бүрийн хамгаалалт, хийсэн ажлаар үнэлнэ.

## Бие даалт 1 16 оноо

| Шалгуур | Оноо | Төлөв ба нотолгоо |
| --- | ---: | --- |
| Нэгдсэн өнгө, бичвэр, нийтлэг загвар | 2 | Хангасан. `css/style.css`, `css/project.css`, `css/services.css`, `css/project-bridge.css` |
| Цэс, холбоос, нэгтгэл | 2 | Хангасан. `sitemap.html`-ийн 30 үндсэн холбоос, статик хувилбарын 819 дотоод заалт шалгагдсан |
| Гишүүн бүрийн 5 өөр бүтэцтэй HTML хуудас ба Flexbox | 5 | Төслийн түвшинд 6 × 5 хуудас, үндсэн баганын Flexbox байрлал бэлэн. [Хуудас бүрийн хүснэгт](team-responsibilities.md) |
| Бодитой, бүрэн, уншихад тохиромжтой агуулга | 3 | Сургалтын жишиг өгөгдөлтэй. Цэс, үнэ, порц, жор, холбоо, цагийн мэдээлэл тайлбартай. [Эх сурвалж](research-sources.md) |
| Маягт, медиа ба ойлгомжтой бүтэц | 2 | Хангасан. `index.html`, `contact.html`, `services/feedback.html`, `media.html`. HTML шошго, төрөл, pattern, медиа заалтыг шалгасан |
| Кодын тайлбар ба хувь хүний оролцоо | 2 | Хэсэгчлэн. Хариуцлагын файл, PR, commit болон [гишүүн бүрийн хамгаалалтын материал](defense-guide.md) бэлэн. Оюутан тус бүрийн өөрийн код ба хамгаалалтыг баталгаажуулах шаардлагатай |

Хуудасны хариуцлага ба өмнөх оролцоог [багийн хүснэгтэд](team-responsibilities.md) тэмдэглэв. Кодын алдаа засах, турших, тайлбар бэлтгэхэд ChatGPT ашигласан.
