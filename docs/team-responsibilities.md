## 1 Нүүр ба мэдээлэл

| Үндсэн хуудас | Хэрэглэгчийн зорилго | HTML ба CSS бүтэц | Лабораторийн хэрэглээ |
| --- | --- | --- | --- |
| `index.html` | Ресторан, цэс, захиалгыг нэг дор олох | Танилцуулга, хоолны карт, аудио, `fieldset`, Flexbox | Ширээний демо, хоолны тоо, нийт үнэ, дэлгэрэнгүй цонх |
| `about.html` | Сэдэв, хооллох үйл явцыг ойлгох | Зурагтай танилцуулга, он цагийн жагсаалт | Семантик бүтэц ба медиа |
| `news.html` | Хөгжүүлэлтийн тэмдэглэл олох | Онцлох нийтлэл, хажуугийн мэдээлэл, огноотой жагсаалт | `fetch()`, хайлт, мэдээний картын animation |
| `contact.html` | Цаг, холбоо болон санал хүсэлтийн маягт олох | Мэдээллийн хүснэгт, шошготой маягт | Имэйл ба текстийн оролтын шалгалт |
| `sitemap.html` | Бүх үндсэн хуудсыг жагсаалтаар олох | Зургаан чиглэлийн холбоос, үе шатны мэдээлэл | Дотоод холбоос ба responsive бүтэц |

Нотлох файлууд нь `css/style.css`, `js/app.js`, `js/home-news.js`, `data/home-news.json`. Хамгаалалтад хайлтын `input` event-ээс картын жагсаалт хэрхэн өөрчлөгдөхийг тайлбарлаад шүүлтийн нэг нөхцөлийг өөрчилж үзүүлнэ.

| `recipe.html` | Хүний тоонд тааруулж орцын хэмжээг бодох | Жорын карт, порцын маягт | JSON орц, `тоо × орц / суурь порц` |
| `media.html` | Хоол хийх бичлэг, тухай өгүүлэмж олох | Видео тоглуулагч, ангилсан медиа | Өгүүлэмжийн хайлт, картын animation |
| `terminology.html` | Нэр томьёо ба хооллох ёсыг мэдэх | Ангилсан тайлбар, нэр томьёоны жагсаалт | JSON-оос орцын гарал ба хадгалалтын карт үүсгэх |

Нотлох файлууд нь таван HTML-ийн `style` хэсэг, `css/project.css`, `js/culture.js`, `data/culture.json`, `media/`. Хамгаалалтад жорын суурь порц ба өөрийн оруулсан тооноос орц хэрхэн өсөхийг нэг жишээгээр бодож үзүүлнэ.

`recipedelge.html` нь жорын нэмэлт дэлгэрэнгүй хуудас. Хуудасны үндсэн 30-д тусад нь тооцоогүй. Лаборатори 1–3-т HTML, маягт ба responsive бүтэц, 4–6-д CSS хөдөлгөөн, JS үйлдэл, AJAX/JSON-ийн жишээг дээрх файлуудаар үзүүлнэ. Гишүүн бүр хоёр минутын танилцуулгадаа таван хуудас, нэг ажилладаг үйлдэл, өөрийн өөрчлөлтийг үзүүлнэ.
