# Бодит туршилтын чеклист — бөглөөгүй
Удирдамжид бүх 30 үндсэн хуудсыг 360, 768, 1280px дээр шалгаж, лаборатори 4–6-ын кодоо хамгаалахыг шаардсан.

## Браузер / Хуудас бүр
- [ ] 360px: хуудас хальж гарахгүй, цэс, зураг, хүснэгт тасрахгүй
- [ ] 768px: layout, товч, форм дасан зохицно
- [ ] 1280px: уншихад тохиромжтой, баганын бүтэц зөв
- [ ] Бүх 30 үндсэн хуудасны холбоос ажиллана
- [ ] Console-д JS алдаа байхгүй
- [ ] Keyboard Tab, Enter, Escape ажиллана
- [ ] `document.documentElement.scrollWidth > window.innerWidth` утга `false`

## JavaScript / JSON
- [ ] `news.html`: JSON мэдээг хайж шүүх
- [ ] `services/index.html`: үйлчилгээ JSON-аар ангилах
- [ ] `booking/faq.html`: асуултуудыг JSON-аас хайх
- [ ] `menu/index.html`: JSON хоол хайх / ангилах
- [ ] `menu/compare.html`: 2 хоол харьцуулах
- [ ] `visit/hours.html`: JSON цагийн хуваарь
- [ ] `recipe.html`: порцын тооцоо
- [ ] `media.html`: өгүүлэмж хайх
- [ ] Network 404: алдааны төлөв; JSON `[]`: хоосон төлөв
- [ ] `booking/manage.html`: localStorage ID хайх, баталгаатай устгах
- [ ] `index.html`: захиалга + хоол сагс
- [ ] CSS animation, `prefers-reduced-motion`
