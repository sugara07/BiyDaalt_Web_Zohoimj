# F.ITM202 — Туршилтын чеклист
Энэ баримт **хийсэн гэж хуурамчаар тэмдэглэсэн тайлан биш**. 6 гишүүн өөрийн ажилтай холбоотой тестийг Chrome DevTools / Live Server дээр хийж, бодит үр дүн, огноо, screenshot нэмнэ.

## Бүх хуудсын responsive тест
Сайт 30 HTML хуудастай. `sitemap.html`-ийн бүх холбоосыг нэг бүрчлэн шалгана.
- [ ] **360px** — nav, гарчиг, хүснэгт, форм тасрахгүй
- [ ] **768px** — баганын шилжилт, товчны хэмжээ зөв
- [ ] **1280px** — зэрэгцсэн баганууд, урт текст зөв
- [ ] Бүх 30 хуудаснуудад эвдэрсэн зураг/холбоос байхгүй
- [ ] Keyboard Tab/Enter/Escape үндсэн үйлдлүүдэд ажиллана
- [ ] Console дээр JavaScript алдаа гарахгүй
- [ ] `document.documentElement.scrollWidth > window.innerWidth` нь бүх хуудасны 3 өргөнд `false`

## AJAX + JSON
- [ ] `news.html` JSON 4 мэдээ ачаалж, хайлт шүүнэ
- [ ] `services/index.html` үйлчилгээний JSON шүүнэ
- [ ] `booking/faq.html` FAQ JSON-аас хайна
- [ ] `menu/index.html` хоолны цэс, үнэ JSON-аас ачаална
- [ ] `visit/hours.html` ажлын цаг JSON-аас хүснэгт үүсгэнэ
- [ ] `culture/recipes.html` JSON жороор порц тооцно
- [ ] Fetch-ийн файл замыг DevTools-д түр сольж 404 алдааны төлөвийг шалгана
- [ ] JSON массивыг түр `[]` болгоод хоосон төлөвийг шалгана
- [ ] Network таб дээр HTTP 200, JSON content-type, ачаалалтын төлөвийг шалгана
