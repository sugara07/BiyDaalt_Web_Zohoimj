# Судалгаа, ашигласан эх сурвалж (2026-11-17)

Эх сурвалжуудыг **ойлголт ба шаардлагыг судлахад** ашигласан. Бусдын HTML/CSS/JS код болон UI framework хуулж тавиагүй.

- W3Schools — [Fetch API](https://www.w3schools.com/js/js_api_fetch.asp): `fetch()`, `response.ok`, JSON ачаалалт.
- W3Schools — [JSON](https://www.w3schools.com/js/js_json.asp): өгөгдлийг бүтэцтэй хадгалах.
- W3Schools — [Responsive media queries](https://www.w3schools.com/css/css_rwd_mediaqueries.asp): 360px / 768px / 1280px орчинд дасан зохицох.
- W3Schools — [CSS animations](https://www.w3schools.com/css/css3_animations.asp): `@keyframes` болон хөдөлгөөн багасгах тохиргоо.
- MDN — [Using Fetch](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch): HTTP 404 үед `fetch()` амжилттай promise буцаадаг тул `response.ok` шалгах.
- OpenTable — [Restaurant website creation](https://www.opentable.com/restaurant-solutions/resources/restaurant-website-creation/): хэрэглэгч хоол, ажиллах цаг, байршил, захиалгын мэдээллийг амархан олох.
- [Restaurant essentials guide](https://support.mydirigible.com/docs/guides/website-planning/restaurant-website/): mobile-first, хүнсний цэсийг HTML текстээр өгөх.

**Өгөгдлийн статус**: Эдгээр эх сурвалж нь сайт ямар боломжтой байхыг зөвлөдөг. Манай `data/*.json`-ын үнэ, хаяг, цаг, танхим, жор, хоолны орц болон түүхүүд нь бодит байгууллагын баталгаат мэдээлэл биш — сургалтын зориулалттай зохиомол жишээ.
