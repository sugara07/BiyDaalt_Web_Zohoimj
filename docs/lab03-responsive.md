# F.ITM202 — Лабораторийн ажил 3

**Хуудас:** `news.html` — Хөх тэнгэр сургалтын вэбийн мэдээний хуудас  
**Branch:** `feature/home-sugara`  
**Хэрэгжүүлэлт:** `css/lab03-news.css` — `body.lab03-news` доторх хуудас дээр үйлчилнэ.

## Хийсэн өөрчлөлт
1. `<meta name="viewport" content="width=device-width, initial-scale=1">`-ийг ашигласан (өмнө нь байсан).
2. Үндсэн нийтлэл болон хажуугийн мэдээллийг Flexbox (`display:flex`) ашиглан байрлуулсан.
3. 1000+ / 800–999 / 721–799 / <=720 гэсэн дөрвөн өргөний нөхцөл ашигласан.
4. 800–999 px-д `max-width:800px`, 721–799 px-д `max-width:720px` өгсөн.
5. 720 px ба түүнээс бага үед нэг баганатай болгож, гарчиг, зураг, цэс, товчны хэмжээг зохицуулсан.
6. Нийтлэг `css/style.css`-ийг өөрчлөөгүй; JavaScript нэмээгүй.

## Туршилт хийх заавар
- VS Code дээр `news.html`-ийг **Live Server** ашиглан нээнэ.
- Chrome → `F12` → `Ctrl+Shift+M` → Responsive горимд оруулна.
- Дараах **бүх 8 өргөн** дээр шалгана: `360, 720, 721, 799, 800, 999, 1000, 1280px`.
- Гарчиг, зураг, хоорондын зай, цэс, sidebar, нийтлэлийн жагсаалт дэлгэцээс хальж гарахгүй эсэхийг шалгана.
- DevTools Console дээр дараах кодыг ажиллуулж хэвтээ overflow байгаа эсэхийг шалгана:

```js
document.documentElement.scrollWidth > window.innerWidth
```

`false` гарвал тухайн дэлгэцийн өргөнд бүх хуудас хэвтээ хальж гараагүй гэсэн үг.
