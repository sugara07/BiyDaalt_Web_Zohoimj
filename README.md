# F.ITM202 — Бие даалт 1 · HTML/CSS статик хувилбар

Энэ branch нь багийн **6 чиглэл × 5 үндсэн хуудас = 30 хуудастай** бие даалт 1-ийн HTML/CSS-only хувилбар. Нэмэлт `recipedelge.html`-тэй нийлээд **31 HTML файл** байна. Багийн гишүүдийн цэс болон соёлын эх HTML/CSS/зураг/медиа ажлыг хадгалсан.

## Хэрэглэх
VS Code эсвэл Live Server ашиглан `index.html`-ийг нээнэ. `sitemap.html` дээр бүх 30 үндсэн хуудас, нэмэлт жорын дэлгэрэнгүй рүү нэвтрэх холбоос байна.

Энэ хувилбар HTML ба CSS ашиглана. Үндсэн хоёр баганатай байрлалууд Flexbox-оор зохион байгуулагдсан. Маягтад `label`, оролтын төрөл, HTML шалгалтын атрибутуудыг харуулсан. Илгээх товч статик хувилбарт идэвхгүй. Жишиг үнэ, хаяг, захиалгын мэдээлэл сургалтын зориулалттай.

Интерактив үйлдлүүд [Бие даалт 2-ын `main` салбарт](https://github.com/sugara07/BiyDaalt_Web_Zohoimj/tree/main) ажиллана.
