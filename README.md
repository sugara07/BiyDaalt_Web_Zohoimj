# F.ITM202 — Бие даалт 1 / HTML + CSS статик хувилбар
Энэ branch бол 1-р шатны зориулалттай **30 HTML хуудасны статик хувилбар**. HTML, CSS, зургуудын холбоосоор ажиллана. JavaScript холбоогүй, AJAX/JSON, localStorage, modal болон бодит интерактив үйлдэл байхгүй.

## Ажиллуулах
VS Code-д `index.html` нээх эсвэл Live Server ажиллуулах. `sitemap.html` дээр 6 багийн 30 хуудас харагдана.

## Шаардлагын тайлбар
- Гишүүн бүр өөрийн 5 хуудасны бүтэц, Flexbox/Grid, semantic HTML, form, media-г тайлбарлаж хамгаална.
- Маягтууд энэ шатанд зөвхөн статик дизайн; мэдээлэл сервер рүү илгээхгүй.
- Интерактив хувилбар `main` branch-д байна.
- Агуулгын бүх үнэ, байршил, цаг сургалтын жишээ. Бодит ресторан биш.
- Төсөлд AI туслах хэрэгсэл ашигласан; гишүүд кодоо шалгаж, өөрийн оролцоо болон туршилтаа бие даан нотолно.

Дэлгэрэнгүй: `docs/team-responsibilities.md`, `docs/test-checklist.md`.
