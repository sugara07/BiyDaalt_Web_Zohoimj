# F.ITM202 — Бие даалт 1 · HTML/CSS статик хувилбар

Энэ branch нь багийн **6 чиглэл × 5 үндсэн хуудас = 30 хуудастай** бие даалт 1-ийн HTML/CSS-only хувилбар. Нэмэлт `recipedelge.html`-тэй нийлээд **31 HTML файл** байна. Багийн гишүүдийн цэс болон соёлын эх HTML/CSS/зураг/медиа ажлыг хадгалсан.

## Хэрэглэх
VS Code эсвэл Live Server ашиглан `index.html`-ийг нээнэ. `sitemap.html` дээр бүх 30 гол хуудас руу нэвтрэх холбоос байна.

Энэ хувилбарт JavaScript, AJAX, JSON файлууд **байхгүй**. Маягт, дижитал үйлчилгээний интерактив үйлдлүүд 2-р шатны `main` branch-д хийгдсэн. Энэ бол жишиг ресторан; бодит үнэ, хаяг, захиалга биш.
