# Хөх тэнгэр — Монгол хоолны вэб сайт

Энэ нь **Вэб зохиомж** хичээлийн сургалтын зориулалттай, Монгол хоолны рестораны **жишиг (демо)** вэб сайт юм.

## Агуулга
- Гар утас, таблет, компьютерт зохицох responsive дизайн
- Бууз, хуушуур, цуйван, хорхогийн SVG дүрслэл ба жишиг үнэ
- HTML хүснэгт, `details` асуулт-хариулт, `audio` жишээ аялгуу
- Ширээ захиалгын форм, JavaScript талбарын шалгалт ба мэдээллийн тойм

## Ажиллуулах
`index.html` файлыг браузер дээр нээх эсвэл VS Code-ын **Live Server** ашиглахад хангалттай. Суулгах нэмэлт сан, сервер, өгөгдлийн сан шаардлагагүй.

## Файлын бүтэц
```text
index.html
css/style.css
js/app.js
img/hero.svg
img/buuz.svg
img/khuushuur.svg
img/tsuivan.svg
img/khorkhog.svg
img/favicon.svg
audio/demo-melody.wav
README.md
```

## Анхаарах зүйл
- Вэб сайт **бодит ресторан биш**; цэсний үнэ, хаяг болон холбоо барих мэдээлэл нь жишээ.
- Захиалгын форм нь **сервер рүү юу ч илгээдэггүй**. JavaScript зөвхөн оруулсан мэдээллийг тухайн хуудсан дээр харагдуулна.
- `audio/demo-melody.wav` бол кодоор үүсгэсэн богино жишээ аялгуу, жинхэнэ морин хуурын бичлэг биш.
- `img/` доторх SVG-үүд нь төслийн өөрийн вектор дүрслэл юм.
