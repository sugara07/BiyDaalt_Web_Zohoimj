Хувилбар: 2026.11.24

Хүргэлтийн машины хөдөлгөөнөөр үйлчилгээний жишиг дүрслэлийг үзүүлсэн. Холын давхарга уулс, ойрын давхарга модод. Бодит хүргэлтийн байршил биш.

## Ажиллуулах
ZIP-ийг задлаад news.html-ийг Chrome эсвэл Live Server-ээр нээнэ. Reduced motion тохиргоо идэвхтэй бол хөдөлгөөн асаах сонголтыг чагтална.

| Объект | Keyframes | Хугацаа |
| --- | --- | --- |
| Тэнгэр | lab4DayNight | 10s, 0.2s delay |
| Нар, сар, од | lab4Sun, lab4Night | 10s |
| Уулс | lab4Move | 16s |
| Мод, замын зураас | lab4Move | 4s |
| Машин | lab4Drive | 2s |

Ойрын модод 4 дахин хурдан. Transform байрлалыг, opacity харагдах байдлыг өөрчилнө. Infinite хөдөлгөөнийг давтана. Hover, focus transition болон 768px, 480px media query ашигласан. Reduced motion үед хөдөлгөөн анх зогсоно; хүсвэл checkbox-оор асаана. Үндсэн хөдөлгөөн JavaScript ашиглахгүй.

## Туршилт
Хөдөлгөөн эхлэх, зогсох, үргэлжлэхийг 360px, 768px, 1280px дэлгэц болон reduced motion нөхцөлд шалгана. Уулын 16s-ийг 4s болговол давхаргын хурд ижил болно.

## Нэгтгэл
Өмнөх таван HTML хуудас, зураг, аудио, CSS, JS хадгалагдсан. Lab 4 news.html-д нэгтгэгдсэн. Шалгалтын дараа main-ийн news.html-д Lab 4-ийн хэсэг болон CSS-ийг нэгтгэж, өмнөх JSON/JS үйлдлийг хадгална.
