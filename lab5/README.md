## Тооцоолол
Нийт = buuz + huushuur. Нийт 0 бол 50:50. Бусад үед Math.round(buuz / total * 100) ба 100 - buuzPercent ашиглана. textContent тоо, хувийг, style.width зурвасын өргөнийг өөрчилнө. addEventListener товч дарах үйлдлийг бүртгэнэ. Reset хоёр тоолуурыг тэглэнэ.

| Туршилт | Бууз | Хуушуур | Нийт | Харьцаа |
| --- | ---: | ---: | ---: | --- |
| Анхны | 0 | 0 | 0 | 50:50 |
| Бууз | 1 | 0 | 1 | 100:0 |
| Хуушуур | 0 | 1 | 1 | 0:100 |
| Олон санал | 3 | 2 | 5 | 60:40 |
| Reset | 0 | 0 | 0 | 50:50 |

Туршилтын зураг нь тусад нь бэлтгэсэн Lab 5 ZIP-д байна. 360, 768, 1280px болон Tab, Enter, Space удирдлага, хуудас шинээр ачаалахад тэглэх нөхцөлийг туршсан.

## Бие даалт 2
Шалгалтын дараа main-ийн index.html-д lab5-choice section болон CSS/JS холбоосыг нэмнэ; хуучин хуудсаар бүхэлд нь солихгүй. Main-ийн сагс, захиалга, modal, AJAX болон бусад гишүүний menu/compare.html-ийг хадгална. JavaScript үйлдэл ба төлөвийн зөв шинэчлэлтийн шалгуурт хамаарна.
